# Interpolator — SWE Lab Assignment 2 Documentation

Documentation artifacts for **Interpolator**, a 1-D paired-data interpolation
tool built as a team submission for **CS346 Software Engineering Lab
(Assignment 2)** at IIT Guwahati.

## What's in this repo

| File                          | What it covers                                                     |
|-------------------------------|--------------------------------------------------------------------|
| `TechnicalDocumentation.md`   | Internal design — modules, data flow, algorithm choices, testing   |
| `UserDocumentation.md`        | End-user guide — how to launch, input format, sample sessions      |
| `Untitled0.ipynb`             | Companion notebook (working scratch / experiments)                 |

## About the project

Interpolator reads a file of 1-D paired samples and lets the user query
interpolated values at arbitrary new input points. The CLI first asks for
the data file (Windows paths use double backslashes), then enters an
interactive query loop.

See `UserDocumentation.md` for the full input format and example sessions,
and `TechnicalDocumentation.md` for the internal architecture.
